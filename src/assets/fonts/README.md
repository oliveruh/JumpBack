# Local fonts

Bangers (400) and Rubik (400, 500, 700), Latin WOFF2 subsets, copied from the
`@fontsource/bangers` and `@fontsource/rubik` 5.3.0 npm distributions.
Both use the SIL Open Font License; their license files are included here.

These are the existing JumpBack typefaces, served locally to preserve the visual
identity when third-party font CDNs are blocked. No npm runtime dependency or
font build step is required. The Latin subset includes Portuguese diacritics.
